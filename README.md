# 📮 filego — 교직원 파일 취합 사이트

영도초등학교 생활안전부에서 쓰는 파일 취합 사이트입니다.
"○○을 제출해주세요" 할 때마다 취합을 하나 만들고, 선생님들은 링크로 들어와 **로그인 없이** 파일을 냅니다.
올라온 파일은 취합별 드라이브 폴더에 `이름_제목.pdf`로 자동 정리됩니다.

- 선생님용: https://soonho3943-code.github.io/filego/
- 관리자용: https://soonho3943-code.github.io/filego/admin.html

## 기능

**선생님**
- 항목 선택 → 이름 선택 → 파일 끌어놓기 → 제출 (여러 파일 가능, 1개당 25MB)
- 다시 제출하면 새 파일로 교체 (이미 냈으면 안내 + 교체 확인)
- 다른 사람의 제출 여부·인원은 보이지 않음

**관리자**
- 취합 만들기 · 수정 · 마감 · 다시 열기 · 목록에서 삭제
- 취합마다 대상자 지정 (전체 교직원 / 직접 선택, 이전 취합 대상 불러오기)
- 제출 현황, 미제출 명단, 메신저용 안내문 복사, 제출 링크 복사
- 제출 삭제, 드라이브 폴더 열기, ZIP 다운로드
- **PDF 하나로 합치기** — 명단 순서대로 PDF·사진을 한 파일로
- 교사 명단 관리 (엑셀 붙여넣기, 인사발령 반영 / 마감한 취합은 당시 명단 유지)

## 구조

```
GitHub Pages (index.html, admin.html)
        │  fetch (로그인 없음)
        ▼
Google Apps Script 웹 앱 (Code.gs) ── 구글 시트: 취합목록 · 교사명단 · 제출기록
        │
        ▼
Google 드라이브: filego 취합 / 2026-10 제목 / 이름_제목.pdf
```

| 파일 | 역할 |
|---|---|
| `index.html` | 선생님 제출 화면 |
| `admin.html` | 관리자 화면 |
| `config.js` | Apps Script 주소, 학교 이름, 파일 크기 제한 |
| `merge.js` | PDF 합치기 ([pdf-lib](https://pdf-lib.js.org)) |
| `style.css` | 디자인 |
| `Code.gs` | Apps Script 서버 코드 (비밀번호는 Apps Script 편집기에서만 설정) |

설치·사용·관리 방법은 [설정방법.md](설정방법.md)를 보세요.
